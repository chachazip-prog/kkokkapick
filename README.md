# 꼬까픽 (KKOKKAPICK) 모바일 데모

우리 아이 옷, 한곳에서.

모바일 UX 검증용 정적 PWA 데모입니다. 홈, 검색/카테고리, 상품 상세, 판매처 가격 비교, 찜, 꼬까핏 프로필/추천 사이즈 흐름을 포함합니다.

## GitHub Pages
Settings → Pages → Build and deployment에서 Source를 **Deploy from a branch**, Branch를 **main / (root)** 로 선택하면 됩니다.

배포 후 주소: https://chachazip-prog.github.io/kkokkapick/

> 현재 상품은 UX 검증용 샘플 데이터이며 실제 제휴 상품 연동 전 단계입니다.
