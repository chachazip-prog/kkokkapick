저장 정보 삭제

현재 안내는 출시 준비 중인 웹 버전 기준입니다.

현재 웹 버전은 아이 정보·찜·희망 가격을 이 브라우저에 저장합니다. 로그인이나 서버 계정 연동 없이 사용할 수 있습니다.

아이 정보 삭제

마이 → 아이 정보 → 삭제할 아이 선택 → ‘이 아이 정보 삭제’를 누른 뒤 확인하세요. 선택한 아이의 별명·월령·키·몸무게가 삭제됩니다. 다른 아이의 정보와 찜·희망 가격은 유지됩니다.

이 브라우저의 모든 정보 삭제

브라우저 설정에서 이 사이트의 저장 데이터 또는 웹사이트 데이터를 삭제하세요. 이 브라우저에 저장된 아이 정보·찜·최근 본 상품·희망 가격이 모두 지워집니다. 다른 기기의 데이터에는 영향을 주지 않습니다.

계정 연동

이 웹 데모에는 서버 계정 삭제 기능이 연결되어 있지 않습니다. 계정 연동이 제공될 때 실제 삭제 경로와 대상 정보를 안내하겠습니다.
