## Campaign display typography

Gowun Dodum (Google Fonts / yangheeryu), SIL OFL1.1. `GowunDodum-Regular.woff` is a local subset for the fixed Korean wordmark and campaign copy, plus Latin/punctuation. Other UI text keeps NanumSquareRound. Missing glyphs use the rounded UI fallback. License: `GowunDodum-OFL.txt`. No browser request to a third-party font service.
