## Positioning
**여러 아기옷을 한곳에서 보고, 사이즈 근거까지.**

KKOKKAPICK helps parents/caregivers discover baby and kids clothing across supported sellers. KKOKKAFIT adds a recommendation only where verified size evidence exists; it tells the user which size to check first, not that an item is guaranteed to fit or be in stock.

## Store short-description candidates
Primary: 여러 아기옷을 한곳에서 보고, 꼬까핏으로 사이즈 선택까지 더 쉽게.
Alternate A: 아기옷 탐색부터 브랜드 사이즈 확인까지, 꼬까픽.
Alternate B: 흩어진 아기옷은 모아보고, 사이즈는 근거를 확인하고.

Use Primary for release candidate. Alternates are experiment copy, not simultaneous claims.

## Screenshot narrative
1. **여러 아기옷을 한곳에서** — real catalog discovery; no unsupported all-stores claim.
2. **우리 아이 기준으로 더 빠르게** — child profile is optional and purpose-limited.
3. **꼬까핏 가능한 상품만 모아보기** — only verified-evidence products receive this state.
4. **왜 이 사이즈인지 근거까지** — show brand guide + recommendation distinction.
5. **판매처 가격을 비교하고 이동** — affiliate/commercial disclosure remains visible.

## Three organic short-form storyboards
### A. 브랜드마다 사이즈가 달라요
0–3s: 같은 80인데 왜 브랜드마다 다르지?
3–8s: two product cards / verified guide differences.
8–13s: child profile -> KKOKKAFIT recommendation.
13–15s: 추천 사이즈를 먼저 확인하고, 실제 옵션은 판매처에서.

### B. 쇼핑몰 탭 그만 늘리기
0–4s: many shopping tabs visual metaphor.
4–10s: KKOKKAPICK discovery feed and filters.
10–15s: merchant comparison -> external handoff disclosure.

### C. 추천에 근거가 없다면?
0–5s: 모르는 사이즈는 아는 척하지 않아요.
5–11s: verified vs insufficient-evidence UI.
11–15s: 확인된 근거가 있을 때만 꼬까핏.

## Claim guardrails
Never use: 정확한 사이즈, 핏 보장, 최저가 보장, 모든 쇼핑몰, AI가 완벽하게 추천.
Allowed with evidence boundary: 꼬까핏 가능, 검증된 사이즈 근거, 먼저 확인할 사이즈 추천, 지원되는 판매처 가격 비교.

## Measurement
Primary launch learning: qualified activation, defined before paid launch as meaningful discovery plus either verified KKOKKAFIT interaction or high-intent save/merchant handoff. Report impressions/CTR only as diagnostic metrics.
