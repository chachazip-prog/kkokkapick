# Mobile UX direction

Target: parents in their 30s–40s who need fast, low-friction apparel discovery while multitasking.

Reference principles, not visual copying:
- familiar commerce/community navigation with a small number of persistent destinations;
- search and child context surfaced before dense controls;
- large touch targets, plain Korean labels, restrained visual decoration;
- product imagery and price hierarchy ahead of metadata;
- KKOKKAFIT presented as decision support, never as an absolute size guarantee.

Information architecture:
1. 홈 — child-context recommendations, seasonal/category shortcuts, clearly disclosed sponsored content.
2. 찾기 — search, stage/category/brand filters, sort, fit filter.
3. 찜 — saved products and price-alert entry points.
4. 마이 — child profile, account/sync state, notification/privacy/support/deletion controls.

Commercial content must remain visually disclosed and must not mimic organic KKOKKAFIT recommendations. Guest browsing remains the default.
