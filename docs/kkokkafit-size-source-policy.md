# KkokkaFit size-source policy

KkokkaFit must not turn a commonly repeated retailer size table into a verified brand recommendation automatically.

## Evidence levels

- **verified**: first-party brand/manufacturer size guide or equivalent authoritative source is confirmed.
- **candidate**: consistent structured size information exists on retailer pages, but first-party provenance has not been confirmed.
- **unverified**: insufficient evidence.

Only **verified** charts may produce a KkokkaFit size recommendation.

Retailer pages may be used to identify what should be verified next, not as silent substitutes for first-party evidence.
