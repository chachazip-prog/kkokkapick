## 마케팅 배경과 앱 배경을 구분한다

카카오톡 App Store의 노란 바깥 배경과 Instagram의 분홍·보라·주황 바깥 배경은 **앱스토어 홍보 프레임**이다. 해당 이미지 안의 실제 앱 화면은 주로 흰 바탕, 진한 텍스트, 작은 기능 아이콘, 사진 중심이다. 원색 바깥 프레임을 전체 앱 배경으로 복제하면 현재 문제를 반복한다.

마미톡 육아 화면에는 실제로 큰 파스텔 영역, 둥근 카드, 여러 아이콘이 있다. 꼬까픽은 Product Owner가 그 반복을 거절했으므로 그대로 가져오지 않는다. 참고할 부분은 **아이 이름과 시기를 즉시 알려 주는 맥락, 부모에게 익숙한 짧은 문구, 필요한 기능이 가까이 있는 구조**다. ABLY의 쿠폰·할인·배송, 마미톡의 기록·참여율도 해당 서비스의 기능이므로 꼬까픽에 근거 없이 추가하지 않는다.

## 실제 화면에서 얻은 설계 기준

### 카카오톡: 구획보다 목록의 읽기 순서

오픈채팅 공개 화면은 작은 아바타, 제목, 한 줄 요약, 우측 시각/배지로 여러 행을 이어 놓았다. 각 행을 둥근 카드로 다시 감싸지 않는다. 제목과 보조 정보의 크기·명도가 다르고 상단 탭은 작다. 하단 내비게이션은 아이콘이 중심이다.

꼬까픽 적용 제안: 마이·최근 본 상품·저장한 희망 가격은 행과 구분선으로 정리한다. 프로필·통계·메뉴를 모두 카드화하지 않는다. 주요 버튼과 행의 터치 영역은 충분히 확보하되 글자까지 과도하게 키우지 않는다. 카카오톡 채팅 말풍선·노란 브랜드색·메신저 기능은 복제하지 않는다.

### Instagram: 사진은 화면에 붙고 기능은 사진 주변에 있다

App Store 홈 피드에서 사진은 내부 화면 가로 폭을 채운다. 작성자와 도구는 작은 상단 행, 반응 버튼은 사진 아래의 짧은 행, 상세 문구는 그 아래에 있다. 공식 2021 Search 사진에서는 3열 그리드, 가는 사진 경계, 사진 위의 둥근 카드 부재, 작은 검색/탭, 고정 하단 아이콘을 확인했다. 일부 사진은 여러 칸을 차지하지만 **꼬까픽은 사용자가 지정한 3×4 균일 피드**를 유지한다.

공식 Search 본문에는 탐색의 검색창을 누르면 최근 검색을 먼저 보여 주고, 입력하면 일치하는 결과를 보여 준다고 설명한다. 2023 설명은 Explore를 추천 사진·동영상의 그리드라고 구분한다. 이는 **탐색과 명시적 검색이 다른 의도를 가진다**는 근거다. 추천 신호·인기 순위·소셜 기능을 꼬까픽에 새로 도입하는 근거는 아니다.

꼬까픽 적용 제안: 사진 모드는 가로 공간을 충분히 쓰고 외부 패널 테두리·큰 제목을 줄인다. 사진 간 여백은 0, 사용자가 요청한 경계선은 1px seam으로 유지한다. 사진 위에는 상품명·가격·가짜 배지가 없다. 선택하면 상품 카드와 판매처 가격을 보여 준다. 사진 보기와 정보 보기는 단순한 전환이고 서로 다른 상품 집합을 몰래 만들지 않는다.

### 마미톡: 부모 맥락은 기능의 이유를 설명한다

육아 공개 화면은 `이도하와 만난 지 1개월 29일차`처럼 아이와 시간을 함께 알려 준다. `월별정보`, `검진/접종`, `성장곡선` 등 목적을 읽을 수 있는 짧은 이름을 쓴다. 쇼핑 공개 화면은 수평 탭과 밑줄, 작은 조건 버튼, 썸네일 옆 상품명·가격 행으로 구성된다.

꼬까픽 적용 제안: 선택한 아이를 `도하 · 6개월 ▾`처럼 짧은 한 행으로 확인·변경하고, 등록되지 않았을 때만 간단한 등록 안내를 둔다. 여러 아이 정보는 현재 로컬 저장 기능을 유지한다. 의류의 사이즈 참고와 장난감/교구의 공식 사용 연령은 분리한다. 정보가 없는 상품에는 적합하다고 단정하지 않는다. 큰 아기 프로필, 건강정보 카드, 발달·의학적 추천, 보호자/아이 정보 업로드는 추가하지 않는다.

### ABLY: 같은 앱에서도 탐색 목적에 따라 밀도가 다르다

App Store 랭킹은 검색 → 짧은 텍스트 탭 → 작은 이미지 카테고리 → 2열 상품 순서다. 상품은 큰 사진, 작은 쇼핑몰/브랜드, 짧은 상품명, 비교적 진한 가격으로 읽힌다. 공개 웹 홈은 같은 모양의 모든 카드를 반복하기보다 캠페인, 카테고리 레일, 3열 사진을 연결한다. 공개 카테고리는 좌측 영역 목록과 우측 세부 텍스트 목록이다.

꼬까픽 적용 제안: 일반 상품 탐색의 2열 정보 카드와 사진 모드의 3열 사진을 목적별로 구분한다. 가격과 판매처를 빨리 읽을 수 있게 상품명보다 안정적인 가격 행을 확보한다. 한 화면에 필요한 상품을 더 노출하되 가격을 하단 바 아래로 밀지 않는다. 검색 필터는 실제 공급 데이터에서 나오는 값만 제공한다. 할인률·후기수·구매수·배송보장·쿠폰·주문·장바구니는 기능·원본이 없는 한 넣지 않는다.

## 현재 06/08/09 시안과의 차이: 우선순위

비교 대상은 `/tmp/kkokkapick-round2-independent-fixed/{06,08,09}-home-430-controlled.png`이다. 실제 상품 사진이 없는 controlled UI이므로 상품 자체의 매력·사진 조합에 대한 평가는 보류한다. 아래는 화면 구성에서 직접 확인한 문제다.

1. **상품 가격까지의 거리가 길다.** 06은 헤더, 확인 상품 수, 캠페인, 브랜드 영역, 섹션명, 탭이 이어지고 첫 상품의 브랜드·가격이 첫 화면에서 보이지 않는다. 운영 커머스 참고 화면처럼 장식과 탐색 도구를 줄여 사진뿐 아니라 실제 상품 정보를 빨리 읽게 해야 한다.
2. **피드가 하나의 큰 패널처럼 보인다.** 08은 3×4 무간격을 지키지만 외곽 여백·외곽 경계·상단 여러 줄 도구가 사진을 사각 패널로 만든다. Instagram 공식 사진에서는 이미지가 탐색 화면 자체를 만든다. 바깥 카드 구조를 줄이고 사진 간 가는 경계만 남기는 방향을 검토한다.
3. **상품을 설명하지 않는 문구와 구획이 반복된다.** `작은 옷, 새로운 발견`, `함께 둘러볼 아이 옷` 같은 제목보다 선택한 아이, 실제 카테고리, 확인 가능한 브랜드·가격 등 구매 탐색에 필요한 맥락을 우선한다. 확인할 근거 없는 `추천`, `인기`, `지금 뜨는`을 만들어 넣지 않는다.
4. **같은 중요도로 보이는 선·탭·입력이 많다.** 브랜드와 캠페인, 검색 입력과 검색 버튼, 사진/정보 전환과 목록 탭이 경쟁한다. 검색 상태에서는 검색을, 사진 탐색 상태에서는 사진을 먼저 보이게 한다.
5. **아이 정보가 탐색 이유로 연결되지 않는다.** 아이 선택은 로컬 기능으로 이미 있으나 탐색 화면에서 누구 기준인지 즉시 읽을 수 있어야 한다. 이를 큰 프로필 카드로 해결하지 않는다.
6. **색만 바꿔서는 개선되지 않는다.** 실제 참고 앱에도 흰 화면이 많다. 차이는 정보 위계, 사진 배치, 밀도, 기능에 따른 작은 색 사용이다. 기존 파스텔을 전면 원색 배경으로 바꾸는 안은 채택 근거가 없다.

## 앱 동작 보완을 위한 검증 계약

다음은 꼬까픽에서 구현·검증할 요구사항이며 참고 앱 실사용으로 확인했다는 주장이 아니다. 시각 방향은 Product Owner 선택 전까지 리뷰 자료로 남기고, 설계와 무관한 동작은 기존 canonical owner에서 개선한다.

원색은 선택 상태, 실제 CTA, 의미가 있는 카테고리 관계에 제한적으로 사용한다. 사진에는 기존 요청의 가는 경계를 적용하며, 큰 파스텔 프로필/아이콘 박스/중첩 카드로 정보를 분리하지 않는다. 화면의 사진 비중과 첫 화면의 브랜드·가격 가시성은 320/375/390/430px의 실제 정상 상품 화면에서 검증해야 한다.

## 근거 파일과 한계

참고 이미지는 제품의 자산·샘플 상품·배포물로 복사하지 않았으며 `/tmp/kkokkapick-commercial-references/`에서만 검토했다. 상세 원본 URL, 조회 시각, HTTP 상태는 `metadata.json`, `downloads.json`, `large-downloads.json`, `instagram-blog-downloads.json`, `public-web-results.json`, `public-browser-results.json`, `ably-navigation-results.json`에 기록되어 있다. 카카오/Instagram/마미톡/ABLY 대표 파일은 각각 `kakao-04.png`, `instagram-search-photo-grid.jpg`, `mamitalk-05-large.jpg`, `ably-08-large.jpg`다. 원본 공개 링크는 위 표에서 다시 조회할 수 있다.

이번 조사는 **꼬까픽 상품 재수집, TTL 변경, 원본 사진 지속 가용성 해결, 소재·실판매 사이즈 확인, 현재 릴리즈 브라우저 QA 또는 iPhone Product Owner 승인**을 수행하지 않았다. ABLY 공개 웹에서의 작은 이동 확인은 네이티브 앱 사용 검증을 대신하지 않는다. 참고 서비스의 브랜드·홍보 문구·사진을 꼬까픽 서비스 자산으로 복제하지 않는다.
