## 구조·공통 동작

- `RefinedScenes.tsx`가 새 06/08/09의 홈·검색·상세·팝업을 소유합니다. 원래 switch의 9개 장면과 해당 후보의 obsolete CSS 규칙을 제거하고, `refinements.css`와 `review-shell.css`로 책임을 나눴습니다. 기존 CSS 끝에 덮어쓰기 규칙을 누적하지 않았습니다.
- 소수의 기능 색상, 둥근 로컬 한국어 글꼴, 사진 경계, 작은 범주의 밑줄 선택 상태. 승인된 두 아이 캠페인은 홈에서 한 번만 사용합니다. 장난감·교구에 의류 사이즈를 표시하지 않습니다.
- 브랜드·카테고리는 신선한 원본의 실제 값을 사용합니다. 저장한 상품은 전체 유효 카탈로그에서 찾으므로 검색 조건 밖에서도 잘못된 상품 카드로 바뀌지 않습니다.
- 사진은 기존 `OriginalPhoto`·`recoverPhoto`·generation·quarantine을 재사용합니다. 오프라인 실패를 영구 오류로 고정하지 않고 정상 대체 원본을 보존합니다. 사진 안내는 이미지 안에만 표시됩니다.
- 실제 스크롤 영역과 찜 팝업 모두 자동 추가. 첫 12장이 전부 보이는 경우에도 아래로 넘기는 동작이 다음 배치를 불러옵니다. 상세 전환은 이미지 상단부터 시작합니다. 사진·상품명·가격·판매처·소재/판매 사이즈·CTA 위계를 구분했습니다.
- 검토 팝업은 앱 소유 native dialog, 실제 서비스 공통 UI는 공식 shadcn/Radix입니다. 검토 시안의 찜은 임시 메모리이며 실제 로컬 저장/아이 기능 검증과 구분합니다.
