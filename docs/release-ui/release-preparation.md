## 코드에서 처리한 릴리즈 문제

- 만료·네트워크 장애에도 홈/검색/사진 피드/찜/마이 URL이 요청한 화면으로 진입합니다. 원본이 유효해지기 전에는 상세·복수 사진 샘플을 열지 않습니다. 새로고침은 사용자의 현재 검색/화면을 URL로 덮어쓰지 않습니다.
- 모든 화면에서 상품 원본 오류와 재시도를 제공합니다. 데모는 실제 수집 시각과 가장 빠른 표시 기한을 한국시간으로 읽고 만료 시 상품 사진 검토 보류를 표시합니다. 이 표시는 건강한 사진·지속 가용성·출시 승인을 주장하지 않습니다.
- 브라우저 저장 공간 접근 차단, 용량 초과 및 잘못된 저장 자료 형식에도 탐색과 상세가 작동합니다. 찜/희망 가격 쓰기에 실패하면 저장 및 화면 상태를 변경하지 않습니다. 최근 기록 저장 실패는 상세 탐색을 막지 않습니다. 기존 저장 자료를 자동 삭제하지 않습니다.
- 서비스 워커는 꼬까픽 소유의 이전 캐시만 제거하며 같은 도메인의 다른 앱 캐시는 유지합니다. 상품/가격 JSON은 오프라인 캐시에 저장하지 않습니다.
- 기존 두 정기 상품 동기화는 canonical main에서만 실행되도록 제한했습니다. legacy 게시 명령이 주석에 들어가 실행되지 않던 구문을 고쳤습니다. 이 변경은 review branch에만 준비하며 운영 일정/호출 범위를 늘리지 않습니다.
- 새 실제 상품 검사에서 발견한 미터 단위 재봉 원단 판매를 의류 탐색에서 제외했습니다. 수집 분류와 브라우저 browsing/deep link 모두 같은 기준을 사용하며 테크원단 완성 아동복은 유지합니다. 원본 955개 자료를 보존하고 실제 표시 954개와 구분합니다.

## 검증과 공개 출시를 구분합니다

1. 구성 테스트와 문법/보안 검사, 원본 오류/저장 실패 회귀를 수행합니다.
2. 승인된 85개 검색으로 새 원본을 수집하고 전체 원본 사진 gate를 통과한 자료만 review branch에 게시합니다. 수집 실행의 코드 SHA와 실제 게시 데이터 SHA를 기록합니다.
3. 수정된 최종 코드와 게시된 원본 자료 조합에서 전체 사진 브라우저 디코딩 및 320/375/390/430px 실제 QA를 수행합니다. 생성한 PNG와 실제 열어 본 PNG 수를 구분합니다. 별도 검토자가 실제 PNG를 확인합니다.
4. 실패·만료는 그대로 기록합니다. 합성 오류 주입, 이전 screenshot, CI 성공으로 실제 상품 사진 검증을 대체하지 않습니다. 재검사로 원본 URL/수집 시각/기한을 연장하지 않습니다.
5. 실제 iPhone Safari에서 히어로, 무간격 3×4 피드/자동 로딩, 복수 사진 도트, 여러 아이 전환/꼬까핏, 월령 근거 없는 놀이 안내, 판매처 이동과 safe area를 Product Owner가 확인해야 합니다.
